# V2.1 Publication Domain

This layer defines the durable control-plane contract for production publication.

## Separation of concerns

Execution status describes the lifecycle of the publication operation:

`PENDING -> CLAIMED -> EXECUTING -> RECONCILING -> SUCCEEDED`

with explicit `FAILED` and `CANCELLED` terminal paths. Delivery state independently describes the external side effect:

`NOT_SENT -> SENT -> CONFIRMED`, or `UNKNOWN` when the external outcome cannot be established.

## Invariants

- publication identity is deterministic and tied to an artifact version and destination;
- publication events are append-only audit records;
- provider credentials are outside the publication domain;
- external provider behavior is isolated behind adapters;
- an unknown delivery outcome must be reconciled before an unsafe duplicate retry;
- terminal successful/cancelled executions cannot transition back into active execution;
- correlation identifiers allow tracing from production/pipeline runs to external publication.

## Deliberate scope

This PR establishes the domain and durable schema. Provider adapters, reconciliation workers, scheduling/rate limits, and operational projections are separate layers so each can be independently certified.
