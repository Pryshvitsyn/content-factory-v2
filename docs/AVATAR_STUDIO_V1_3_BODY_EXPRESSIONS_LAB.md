# Avatar Studio V1.3 — Body + Expressions Lab

V1.3 extends the existing Avatar Studio and its V1.2.1 controlled reference-generation boundary. It does not add video, voice, publishing, or an independent continuity system.

## Strict level boundary

The authoritative input is the current human-certified L1 Passport, paired with its Identity Version and Identity Lock. Plans, generated or uploaded candidates, automatic QA, KEEP decisions, and individual reference certifications all remain L1. Only an immutable, explicit human `L2_CERTIFICATION_EVENT` for the current dependency set advances the avatar to L2.

L2 requires certified `CHEST_UP_NEUTRAL`, `FULL_BODY_STANDING_NEUTRAL`, `SEATED_NEUTRAL`, `NEUTRAL`, `WARM_SMILE`, and `SERIOUS_CONCERNED` references. Mouth Calibration is durable and certifiable now, but is optional for L2 and reserved as a future talking-head eligibility prerequisite.

## Identity, build, and presentation

Body Build versions contain only human-approved, non-sensitive visual continuity descriptors. Unavailable facts remain `UNKNOWN`; exact medical/body measurements and unsupported sensitive inference are rejected. `L2_NEUTRAL_REFERENCE_OUTFIT` is classified as `REFERENCE_PRESENTATION`: it is neither Identity nor a Wardrobe Pack and never unlocks L3.

## Generation and evidence

Provider-neutral specs request `CHARACTER_BODY_REFERENCE`, `CHARACTER_EXPRESSION_REFERENCE`, or `MOUTH_SHAPE_REFERENCE`. The catalog currently advertises these capabilities only for the configured reference-image adapter path that can technically accept approved images. Each candidate costs one explicit provider call. Cost remains `UNKNOWN` when the catalog has no verified amount; the operator must set a budget ceiling and acknowledge uncertainty.

The sequence is `PLAN → FRESH PREFLIGHT → HUMAN APPROVAL → EXPLICIT GENERATE → IMMUTABLE ARTIFACT → QA → HUMAN REVIEW → INDIVIDUAL CERTIFICATION → FINAL PACK CERTIFICATION`. Automated retries are zero. Manual uploads enter through Asset Intake, Gate 0, explicit source roles, the same QA, and the same certification boundary.

## QA and dependency invalidation

Body, expression, and mouth analysis extends V2.10 continuity and V2.10.2 reference geometry evidence. It reports named dimensions, warnings, failures, anatomy defects, and measurable confidence rather than treating one opaque score as truth. Human certification remains mandatory.

Identity Version, Identity Lock, Passport certification, and Body Build version are explicit dependencies. Changing Identity invalidates L1 and L2; changing Passport or Body Build makes the prior L2 event non-current. Historical artifacts and events remain immutable.

## First paid smoke boundary

After code review and separate operator approval, use one synthetic L1 avatar and plan exactly one `CHEST_UP_NEUTRAL` candidate. Confirm cost/budget, approve once, generate once, then verify artifact ingest, identity continuity, QA, and human review. Do not generate full-body, seated, expression, or mouth assets until that path succeeds.
