# NVIDIA provider and model routing

NVIDIA is represented as one provider credential with independently selectable models.

## Credential boundary

Use one provider credential such as `NVIDIA_API_KEY` for hosted NVIDIA API access. Do not create one secret per model. For self-hosted NIM, deployment credentials such as `NGC_API_KEY` are separate infrastructure concerns.

## Model boundary

Models are configuration, not credentials. The router resolves a capability to a model:

- `text_generation` → Nemotron
- `image_generation` → FLUX.2-klein by default
- `image_editing` → FLUX.2-klein by default

A capability may explicitly select another NVIDIA model without changing credentials.

## Production rule

A model route is only a selection. The provider adapter must still return a real artifact. Placeholder media is never a successful production result.
