# V2.9.2 Universal Media Stack

V2.9.2 extends the V2.8 provider catalog into one explicit, provider-neutral production configuration. Video model family, provider model ID, capability, profile, resolved settings, audio strategy, voice provider/model/voice ID, semantic critic, and master profile remain separate fields. The resolved object is stored in the existing immutable job JSON/provenance path; no schema migration is required.

## Selection and routing

The centralized presets are `ECONOMY`, `STANDARD`, `PREMIUM`, and `CUSTOM`. They are defaults, not locks. Operator values override brand preferences, which override preset defaults. `STANDARD` currently recommends Runway Gen-4.5. `PREMIUM` uses a certified premium provider/model registration. `CUSTOM` requires an explicit provider, model family, provider model, and profile.

There is no `AUTO` paid route and no silent fallback. The catalog exposes support status separately from configuration status. A model may be supported while its credentials are not configured; the Dashboard shows both states. Provider/model capability checks fail closed before execution.

Canonical families include `WAN_3` on Replicate (`alibaba/wan-3`) and Alibaba Model Studio (`wan3.0-video`), and `SEEDANCE_2_5` on Replicate (`bytedance/seedance-2.5`) and fal (`bytedance/seedance-2.5/text-to-video`). Family identity never substitutes one provider for another.

## Audio ownership

Audio strategy is explicit:

- `EXTERNAL_VOICE`: native video audio is disabled and exactly one external voice asset is generated.
- `NATIVE_VIDEO_AUDIO`: the video provider owns spoken dialogue and no voice asset is generated.
- `HYBRID`: the video provider generates ambience/effects without speech; the external voice provider owns exact narration.
- `NO_VOICE` and `NO_AUDIO`: no narration asset is generated and native audio is disabled.

The resolved stack records `dialogueOwner` and `preventDuplicateNarration`. ElevenLabs is optional through `ELEVENLABS_API_KEY`, model `eleven_v3`, with a distinct required `voiceId`. OpenAI TTS remains supported. Voice selection priority is operator, then brand, then preset.

## Direct Alibaba safety and recovery

Alibaba direct execution requires all of:

```text
DASHSCOPE_API_KEY
ALIBABA_MODEL_STUDIO_WORKSPACE_ID
ALIBABA_MODEL_STUDIO_REGION=singapore
```

`beijing` is also accepted. Region selection maps to a fixed official host; arbitrary endpoint overrides are rejected. Workspace identifiers are validated before URL construction. Submission uses the required asynchronous header. The durable executor records the returned task ID before polling and recovers that task after interruption rather than submitting a duplicate. Result URLs are downloaded into immutable artifact storage because provider URLs are temporary.

## Pricing and preflight

The central pricing registry records provider, model, component, unit, verification date, source, and status: `VERIFIED`, `PROMOTIONAL`, `STALE`, or `UNKNOWN`. Promotional records become `STALE` after their expiry. Unknown components make the aggregate estimate unknown; they are never treated as zero. Preflight exposes the component breakdown and external-call counts and performs zero provider executions.

Pricing facts were verified on 2026-08-27 against official provider pages. The Alibaba Wan 3 promotion is recorded with its 2026-09-24 00:00 UTC+8 expiry. Runtime code automatically marks it stale after that instant.

## Testing and paid boundary

Run:

```bash
npm run test:v2.9.2
npm run dashboard:build
```

All adapter tests use synthetic mocks. They cover Wan 3 and Seedance request translation, model-family isolation, audio ownership, ElevenLabs retry and voice-ID mapping, Alibaba async recovery without duplicate submission, pricing expiry, and immutable production input. No real media configuration is executed by the suite. Publication, certification, and production deployment remain explicit human decisions.
