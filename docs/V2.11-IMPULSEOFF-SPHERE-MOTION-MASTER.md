# V2.11 — ImpulseOff Sphere Motion Master

This is a media-production workflow. It produces and validates immutable video assets; it does not add a procedural, shader, CSS, or application-side sphere effect.

## Workflow

1. Register an approved reference artifact and create a motion spec with `createMotionSpec`.
2. Create a plan with `createGenerationPlan`; it has one exact canonical request, one expected paid call, and centralized positive/negative prompts.
3. A human approves `visual_spec` and `generation_prompt`. `SphereMotionMasterService.generate` fails closed unless `LIVE_PAID_GENERATION=true` and these approvals are supplied by the calling durable workflow.
4. Register generated media as an immutable artifact. Human approval of the generated master is separate from segmentation.
5. Annotate real IN/OUT boundaries in a manifest, then validate it with `validateManifest`. No sample timing is production timing.
6. Use the FFmpeg helpers to extract segments and first/middle/last frames. Run loop QA and obtain separate loop, segmentation, and final-export approvals before making an export available to ImpulseOff.

`validateManifest` rejects missing source media, invalid/overlapping ranges, unsupported kinds, and loop flags on non-loop motion kinds. `sphere-motion-media` supplies exact trimming, frame extraction, repeated-loop previews, and first/last difference render commands. `validateLoop` extracts actual grayscale first/last frames and reports frame/average, rim, and background difference; intensity-weighted center displacement; apparent-radius change; and luminance jump. Numeric checks are QA evidence only: human visual review remains mandatory.

## Export layout

`exportPaths(root)` returns the immutable artifact convention `impulseoff/sphere-motion/v1/{master,frames,segments,segment-frames,manifest,qa}`. A manifest is only valid after actual annotation and includes source, width, height, fps, and non-overlapping spans.

## Controlled real generation

No provider action is performed by plan creation or tests. After the reference artifact and the two required human approvals are recorded, create an approvals JSON array containing the recorded `visual_spec` and `generation_prompt` approvals, then run exactly one controlled generation:

```bash
LIVE_PAID_GENERATION=true node scripts/impulseoff-sphere-motion-master.js --execute --brand-id impulseoff --reference artifact://YOUR-APPROVED-REFERENCE --approvals /absolute/path/to/recorded-approvals.json
```

The command is plan-only without `--execute`; with it, it submits one Alibaba Wan 3.0 Video IMAGE_TO_VIDEO request, downloads the result, and creates an immutable pending-review artifact. Required configured environment is `DASHSCOPE_API_KEY`, `ALIBABA_MODEL_STUDIO_WORKSPACE_ID`, and `ALIBABA_MODEL_STUDIO_REGION`. Cost is not stated because the repository catalog marks this model's pricing as promotional rather than a stable quoted API price.
