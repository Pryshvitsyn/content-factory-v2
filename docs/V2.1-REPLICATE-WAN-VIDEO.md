# Replicate Wan 2.2 video adapter

The Replicate adapter implements the existing provider-neutral `video-generation` capability for `wan-video/wan-2.2-t2v-fast`. It does not change the V2.1 stage graph or replace NVIDIA Cosmos.

## Configuration

- `REPLICATE_API_TOKEN` supplies the bearer credential.
- `VIDEO_PROVIDER=replicate` makes Replicate the preferred video route.

Without `VIDEO_PROVIDER`, normal configured priorities apply. Credentials are never included in logs, artifacts, or provenance.

## Vertical defaults

- resolution: `720p`;
- aspect ratio: `9:16`;
- frames: `81`;
- frames per second: `16`;
- `go_fast`: enabled.

All values remain configurable in the asset generation requirements. The current model schema does not expose a negative-prompt input, so the adapter does not send an unsupported field.

## Prediction lifecycle

The adapter creates an asynchronous prediction, polls bounded `queued`, `starting`, and `processing` states, handles every terminal state, and enforces a local timeout plus Replicate's `Cancel-After` deadline. Transient polling and download failures are retried within a small bound. Prediction creation is not blindly retried because a network-ambiguous POST could create a second paid generation.

On success, the temporary output URL is downloaded immediately. Only non-empty MP4 bytes enter the provider result and immutable artifact flow. Provider, model, prediction ID, generation parameters, metrics, and the original temporary URL are stored in a separate immutable provenance artifact; the URL is never the permanent media asset.

## Idempotency and cost safety

The stable Factory media idempotency key includes brand, production, and asset identity. Concurrent calls with the same key share one in-flight Replicate operation. Before generation, master production checks the existing deterministic immutable artifact key and reuses its bytes, preventing a completed operation from being paid for again on retry.

Normal tests and CI use injected fake HTTP responses. A live paid request is never part of certification and must be invoked manually with explicit approval.
