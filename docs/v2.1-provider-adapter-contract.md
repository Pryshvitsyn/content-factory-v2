# V2.1 Provider Adapter Contract

The Content Factory core never talks directly to a platform API.

## Boundary

`Publication Domain -> Provider Adapter -> External Platform`

The adapter owns provider-specific transport and receives credentials only through the credential provider boundary.

## Contract

Each adapter declares:

- provider
- account identity
- capabilities
- publish operation
- optional reconciliation operation

Every publish request must carry a stable `idempotencyKey`.

## Capabilities

- `PUBLISH`
- `IDEMPOTENCY`
- `RECONCILE`
- `SCHEDULE`
- `UPDATE`
- `DELETE`

Unsupported capabilities are rejected at construction time. Reconciliation is mandatory when the adapter declares `RECONCILE`.

## Security boundary

Credentials are resolved by `credentialProvider` and are not stored in the publication domain. Provider implementations receive credentials only inside the adapter boundary.

## Scope

This PR defines and certifies the interface only. Concrete YouTube/Instagram/TikTok implementations are separate integrations.
