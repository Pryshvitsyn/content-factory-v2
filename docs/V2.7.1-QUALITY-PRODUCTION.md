# V2.7.1 QUALITY production pass

V2.7.1 keeps the certified production engine and adds an operator-side creative planning and quality-profile boundary before canonical V2.5/V2.6 input normalization.

## QUALITY configuration

Production QUALITY is fail-closed. `QUALITY_VIDEO_MODEL` must name a model supported by the installed Replicate adapter. The application does not silently fall back to `wan-video/wan-2.2-t2v-fast`. That model remains available only through the explicit `legacy-fast-test` profile.

The supported controls are documented in `.env.example`: provider, model, resolution, fast/quality mode, prompt optimization, interpolation, frame count, FPS, sample shift, and deterministic seed strategy. The current adapter supports 480p and 720p; the production profile defaults to the highest supported value, 720p.

## Creative planning and Brand Brain

The deterministic planner emits structured shot JSON before provider routing. Every shot records purpose, duration, subject, action, environment, emotional intent, framing, camera, lens/composition, lighting, style, continuity identity, provider prompt, and negative guidance. Operator input is authoritative. Canonical Brand Brain facts are included only when present; an empty Brand Brain is represented as `EMPTY_OPERATOR_ONLY` and no facts are invented.

Continuity metadata also includes stable appearance, wardrobe, environment, lighting/color, props, and reference-media placeholders. The placeholders prepare the provider contract for reference-image or image-to-video adapters without claiming the current text-to-video adapter supports them.

The current text-to-video provider cannot guarantee identical character identity between generations. Continuity identity is durable prompt/provenance guidance, not a face-consistency guarantee.

## Per-shot regeneration

Per-shot regeneration has a separate preflight and explicit confirmation. Its durable command expects exactly one new video generation, zero audio generations, and one provider call. A replacement asset ID is created while prior media executions and artifacts remain immutable. Existing successful assets are reused by the V2.5 durable media executor, FFmpeg rebuilds a new immutable master, and the review service requires human approval for that exact master. Publication remains disabled.

`migrations/20260824_v2_7_1_shot_regenerations.sql` adds durable, workspace/brand-scoped command state. The migration is forward-only: disabling V2.7.1 routes is the recovery path; successful revision provenance and artifacts must not be deleted.
