# V2.9.2.4 Recovery Evidence Reuse

Semantic-only recovery must never rewrite already-persisted sampled-frame evidence from JSON-round-tripped Buffer objects.

The durable semantic attempt stores only immutable frame descriptors (storage key, content hash, analysis hash, timestamp, and artifact identity). Before post-PASS paid media continuation, recovery reloads and hash-verifies those exact frame bytes from artifact storage. The master receives materialized Buffers, so existing frame artifacts are reused idempotently with byte-identical content.

Safety invariants:

- video generations remain 0 during semantic recovery;
- a reusable semantic PASS causes 0 semantic provider calls;
- stored semantic attempt JSON contains no raw frame bytes;
- frame evidence is hash-verified locally before any post-PASS speech generation;
- existing speech artifacts are reused; missing speech may be generated only under the existing durable-media rules;
- genuine provider ambiguity remains blocked;
- STANDARD final-master policy does not add another semantic provider call.
