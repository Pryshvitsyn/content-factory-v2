# V2.1 Publish Execution

Publication is the final execution boundary after the publication readiness gate.

## Rules

1. A publication request must have an allowed readiness gate.
2. A blocked gate fails with `PUBLICATION_BLOCKED`.
3. Publication identity is deterministic for artifact version + destination unless an explicit idempotency key is supplied.
4. A successful publication is persisted by its publication key.
5. Repeating the same publication request reuses the existing successful result and must not invoke the external publisher again.
6. Publication execution does not modify artifacts or validation results.
7. Provider-specific transport remains behind the publisher boundary.

## Certification

The initial implementation certifies:

- allowed publication succeeds;
- repeated identical publication is idempotent;
- external publisher is called exactly once;
- blocked publication never reaches the publisher.
