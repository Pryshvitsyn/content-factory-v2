# NVIDIA video provider adapter

The factory core uses the provider-neutral `video-generation` capability. NVIDIA is an adapter, not a core dependency.

The adapter is configurable because NVIDIA currently exposes multiple video deployment shapes. For Cosmos3-Nano NIM, the documented NIM deployment uses `POST /v1/infer` and returns an MP4 as `b64_video`; NVIDIA's Visual Generative AI stack also documents an OpenAI-compatible `POST /v1/videos/generations` for supported video deployments.

Configuration:

- `NVIDIA_API_KEY` — bearer credential.
- `NVIDIA_VIDEO_BASE_URL` — deployment base URL.
- `NVIDIA_VIDEO_ENDPOINT` — endpoint path, default `/v1/infer` for Cosmos-style NIM.
- `NVIDIA_VIDEO_MODEL` — model identifier, default `nvidia/cosmos3-nano`.

No stock-image fallback or placeholder media is used. A successful adapter call must return actual MP4 bytes or an actual video URL and is normalized to the provider contract.
