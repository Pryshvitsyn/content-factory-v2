# V2.1 Publication Gate

The publication gate is the deterministic downstream boundary for validation readiness.

## Rules

- Every required validation must exist for the target artifact version.
- `FAIL` blocks publication.
- `WARN` is non-blocking unless policy explicitly promotes it to blocking.
- `PASS` is non-blocking.
- Missing required validation never counts as `PASS`.
- When multiple results exist for a validation type, the newest result is authoritative.
- The gate is provider-neutral and does not alter execution, lease, retry, or concurrency behavior.

The gate returns a structured decision and throws `PUBLICATION_BLOCKED` when publication is attempted without readiness.
