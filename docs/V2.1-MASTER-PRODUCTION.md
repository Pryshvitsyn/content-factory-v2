# V2.1 Master Production Vertical Slice

## Purpose

This vertical slice turns approved structured production plans into a technically validated MP4 master. It extends the certified V2.1 stages without changing their order, ownership, retry, lease, artifact, validation, or publication semantics.

```text
SCRIPT + SHOT_PLAN + ASSET_PLAN
  -> brand-scope validation
  -> image/video/voice generation
  -> deterministic timeline
  -> FFmpeg MP4 render
  -> editorial and technical quality gate
  -> immutable master artifact
  -> mandatory human review
```

## Supported deliverable

The initial certified profile is a vertical short-form master:

- MP4;
- 1080x1920;
- 30 fps;
- H.264 video and AAC audio by default;
- uninterrupted visual coverage;
- explicit hook and CTA;
- voice copy derived from the approved script;
- deterministic shot timing and asset identity.

Profiles are configurable, but a changed profile is a different render input and therefore produces a different immutable master identity.

## Media providers

Media generation remains behind the provider gateway. The default provider composition is:

- NVIDIA: text and video;
- Replicate Wan, when `REPLICATE_API_TOKEN` is configured: video;
- OpenAI media, when `OPENAI_API_KEY` is configured: image and speech.

No credential is stored in production, asset, artifact, or provenance records. A missing capability fails closed instead of creating placeholder media.

Every generated media result must contain durable bytes. Each image, video, or voice result is persisted as an immutable, brand-scoped artifact before rendering. Provider-hosted temporary URLs are not accepted as the only master input. Pre-resolved reusable media may be supplied only with matching brand identity and an existing immutable artifact reference.

## Quality gate

The master quality result checks:

- explicit hook and delivery in the first scene;
- explicit CTA and delivery in spoken copy;
- exact approved voice copy;
- scene/shot timing agreement;
- complete visual coverage;
- declared continuity/visual style;
- target resolution, frame rate, duration, video stream, and audio track.

A passing automated result only sets `readyForHumanReview`. It never grants publication authority. Every rendered master returns `publicationAllowed: false` and `AWAITING_HUMAN_APPROVAL`.

In V2.3, callers may inject `ControlReviewService` into `MasterProductionOrchestrator`. A passing master is then registered as immutable review evidence in PostgreSQL before the build returns. The review identity includes the exact artifact storage key and content hash; a later regeneration always requires a new human decision. This integration does not change publication state.

## Brand isolation and artifact safety

`brandId` is mandatory. Conflicting brand identity on the script, shot plan, or asset plan fails with `BRAND_SCOPE_MISMATCH`. The brand identity participates in provider metadata and deterministic master idempotency.

The rendered MP4 is stored as a new immutable artifact version. Regeneration never overwrites a published or certified artifact.

## Certification

```bash
npm run test:v2.1:openai-media
npm run test:v2.1:master-production
npm run test:v2.1:master-renderer
npm run test:v2.1:replicate-video
npm run test:v2.1:replicate-master
```

The renderer test invokes real local `ffmpeg` and `ffprobe`, generates synthetic media, renders an MP4, and verifies the resulting streams.

The public package entry point exports `createMasterProductionFactory`. It composes provider routing, immutable filesystem artifact storage, FFmpeg rendering, and the master orchestrator. Calling `build` requires explicit `productionId`, `brandId`, `workerId`, `script`, `shotPlan`, and `assetPlan` inputs.
